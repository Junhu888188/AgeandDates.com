# Age & Dates — V1.2

Static website package for AgeAndDates.com.

## Deploy
Upload the contents of this folder directly to the root of your GitHub repository. `index.html` must be in the repository root.

Recommended Cloudflare Pages settings:
- Framework preset: None
- Build command: blank (or `exit 0`)
- Build output directory: `/`

Before public launch, review the contact email, Privacy Policy, Terms, analytics, and advertising configuration.
