# Localized tool improvements — 29 September 2026

Search Console showed 116 impressions and one click in the selected 28-day report, with data through 26 September. The four localized pages accounted for 74 impressions. The Indonesian age page received 41 impressions, including birth-year queries; German queries also included birth years. These are early signals, not proof of sustained traffic.

## Changes

- Indonesian and German age calculators now accept a birth year and reference year in a separate form. Results show the possible ages before and after the birthday, without inventing a birth date. The reference year defaults to the visitor's current year.
- The Portuguese add/subtract calculator explicitly names both operations and links to the new date-difference tool.
- Added `/pt-br/calculadora-entre-datas/` as one adjacent-tool experiment. It supports inclusive counting, reversed dates, calendar years/months/days, local validation and copying results.
- Updated reciprocal language annotations, navigation, homepage directory and sitemap. Updated the generator so rebuilding preserves the changes. Python file handling explicitly uses UTF-8 and checks use portable URL paths on Windows.

## Validation

`node localized.test.cjs`, `node calendar.test.cjs`, `node app.test.cjs`, and `python check-localized.py` pass. New checks cover birth-year boundaries and invalid inputs, Portuguese date differences, reversed dates, inclusive counting and leap days. Browser checks confirm Indonesian/German year results, invalid-year handling, and Portuguese exclusive/inclusive results. A 390px viewport check found no horizontal overflow on the German page. This is browser emulation, not a physical-device test or native-speaker review.

Compare the same page/query groups over subsequent complete reporting periods. Track relevant impressions, clicks and query positions; assess the new Portuguese page separately.
